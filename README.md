# OTPFloodGuard Benchmark

This repository contains the reproducibility package for the paper:

**OTPFloodGuard: A Public-Evidence-Constrained Benchmark for Lightweight OTP Flooding Detection**

## Purpose

OTPFloodGuard is a simulated benchmark for studying lightweight OTP flooding detection under public-data constraints. The benchmark is not based on real OTP logs and does not claim production-level detection accuracy. It is designed to make simulation assumptions, feature definitions, difficulty settings, baseline models, and evaluation outputs inspectable.

## Repository Structure

- `src/run_otpfloodguard_experiment.py`  
  Main experiment script. It generates the simulated benchmark data, trains baseline models, evaluates rule baselines, runs stress tests, exports result CSV files, and generates figures.
- `data/`  
  Simulated benchmark dataset generated by the script.
- `results/`  
  CSV files supporting the reported tables and results.
- `figures/`  
  Figures used in the paper.

## How to Run

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Run the experiment from the repository root:

```bash
python3 src/run_otpfloodguard_experiment.py
```

The script exports generated data, result CSV files, and figures into the `data/`, `results/`, and `figures/` folders.

Full reproduction may take several minutes because the script includes multi-seed evaluation, generator-shift testing, ablation, attack-intensity analysis, cost-sensitive threshold analysis, and diagnostic figure generation.

## Result File Mapping

- `results/metrics.csv`  
  Main Overlap benchmark model comparison.
- `results/multi_seed_summary.csv`  
  Seven-seed stability results.
- `results/cross_generator_metrics.csv`  
  Generator-shift robustness results.
- `results/difficulty_metrics.csv`  
  Easy, Overlap, and Adaptive difficulty results.
- `results/attack_intensity_metrics.csv`  
  Attack-intensity stress-test results.
- `results/ablation_metrics.csv`  
  Feature-group ablation results.
- `results/cost_sensitive_thresholds.csv`  
  Threshold selection under relative false-negative and false-positive costs.
- `results/error_analysis_summary.csv`  
  Representative false-positive and false-negative error patterns.
- `results/feature_dictionary.csv`  
  Feature definitions used in the simulated benchmark.
- `results/feature_correlation.csv`  
  Feature-correlation sanity check.
- `results/test_predictions.csv`  
  Seed-42 test predictions used for threshold and error analysis.

## Important Limitation

The dataset is simulated. The reported model scores should not be interpreted as real-world OTP flooding detection accuracy. Real-world validation would require anonymized or aggregate OTP request logs and appropriate institutional privacy review.
